# Web Programming – Week 4

React exercises for Metropolia's Web Programming course. Each exercise is available in its own Git branch.

## Completed exercises

| Branch             | Exercise                  | Implementation                                                                                                                                |
| ------------------ | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `first-component`  | First Components          | `Home` and `MediaRow` components, a media table rendered with `map()`, and props.                                                             |
| `state-management` | React State Management    | Media selection with `useState`, conditional rendering, and a `SingleView` for images and videos.                                             |
| `routing`          | Routing with React Router | Shared `Layout` and navigation between Home, Profile, Upload and Single views. Media navigation with `Link`, `useLocation` and `useNavigate`. |
| `hooks`            | React Hooks               | Data fetching with `useEffect`, Media API integration, user data fetching with `Promise.all()` and dynamic rendering.                         |

# Web Programming – React

React exercises completed during the Web Programming course at Metropolia University of Applied Sciences.

## Week 5

### 1. Custom Hooks
Refactored API fetching logic into reusable custom hooks to separate data handling from UI components.

[Published application](https://users.metropolia.fi/~jonatago/custom-hooks/)

### 2. Forms in React
Implemented login and registration forms using custom hooks, API authentication, token storage and user profiles.

[Published application](https://users.metropolia.fi/~jonatago/forms/)

### 3. Shared State (Context)
Implemented shared authentication state with React Context, automatic login, conditional navigation and protected routes.

[Published application](https://users.metropolia.fi/~jonatago/context/)

### 4. File Upload

Implemented authenticated image and video uploads using FormData, custom API hooks, file previews and Media API integration.

[Published application](https://users.metropolia.fi/~jonatago/upload/)
